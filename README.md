# Raypong

A small game written in C using raylib.

## Requirements

- Clang with C23 support
- GNU Make
- OpenGL and X11 libraries (the Makefile links against these Linux system libraries)

The raylib header and static library are already included in `vendor/`.

## Build and run

The default target builds the debug version and starts the game.

```bash
make
```

```bash
make debug    # Build the debug version
make run      # Build and run the debug version
make release  # Build the optimized version
make clean    # Remove generated build files
```
## Project structure

- `src/` — C source files
- `include/` — Header files
- `vendor/` — The raylib header and static library
- `build/` — Compiled objects, dependency files, and executables generated by Make
- `Makefile` — Build targets and compiler/linker settings
